# Class 07 — HTML Forms

## What you will learn
- The purpose of the `<form>` element
- Why labels matter
- Common HTML input types
- Select, radio, checkbox, textarea, and buttons
- Built-in HTML validation
- Small accessibility and mobile UX improvements

## Mentor note
Do not rush through the example. Change one input type at a time and watch how the browser's behavior changes.

## Homework
Build your own responsive registration form. Use semantic HTML, connected labels, useful input types, and built-in validation. Then style it so it remains comfortable to use on a small phone screen.
