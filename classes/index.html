CLASS 07 · HTML FUNDAMENTALS

HTML Forms

Forms are how a webpage listens to people. In this lesson, we will build a practical contact form and learn why each HTML element is there, not just how to make it look good.

01

What a form actually does

A form groups controls that collect information from a user.

The <form> element is the container. Inside it, we use controls such as <input>, <select>, <textarea>, and <button>. A good form starts with a clear label for every field.

Mentor tip: Do not choose an input because it looks nice. Choose it because it describes the kind of information you are asking the user to provide.
02

Common form controls

These are the controls you will use again and again.

text

Short text

Names, cities, usernames and other brief answers.

email

Email

Use the semantic input type so browsers can provide useful validation and keyboards.

password

Password

For secret values that should not be displayed as normal text.

radio

One choice

Use a radio group when the user should select one option from several.

checkbox

Multiple choices

Use checkboxes when more than one option can be selected.

select

Dropdown

Useful when there are several known options but you want to keep the form compact.

04

Small details that make a form better

Good forms are quiet. They guide the user without getting in the way.

  • Connect every <label> to its control with matching for and id values.
  • Use the most specific input type you can, such as email instead of generic text.
  • Give required fields a real required attribute instead of relying only on visual decoration.
  • Keep touch targets comfortable on mobile screens.
  • Use HTML validation first; add JavaScript when the experience genuinely needs it.
