# HTML & CSS Starter Class

Welcome to your learning workspace.

This starter collection shows how the library organises a class folder. Each file in this directory appears automatically in the class workspace after the repository is published.

## Learning goals

- Understand the basic structure of an HTML document.
- Connect an external CSS file to a page.
- Change content and styles, then refresh the preview.
- Add your own practice tasks and examples.

## Try it

Open the Index file in this class card to see a live preview. Open Style to read the stylesheet. You can add additional files or folders here without editing the website code.

## Suggested folder structure

You can organise a larger class with subfolders such as lessons, examples, assignments and projects. The catalogue builder detects nested folders and shows them as subtopics.
