# Obaid Web Lab

A browser-first personal command center for Mohammed Obaidul Hoque.

## Included
- Overview dashboard
- Local-first HTML/CSS/JS Web Lab with live preview
- Data analytics workflow
- Digital marketing planning
- Study Hub with focus timer
- Projects board
- Notes saved to localStorage
- Task manager with completion state
- Resource hub
- Dark/light theme
- Command palette
- Responsive mobile navigation
- No build step and no external runtime dependencies

## Run
Open `index.html` in a browser, or deploy the repository as a static site with GitHub Pages.

All personal workspace data is stored locally in the browser.
